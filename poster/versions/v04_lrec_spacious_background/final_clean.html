Benchmark DesignFour molecular representations, one protocol

We compare fingerprints, a frozen SMILES encoder, 2D GNNs and 3D SchNet under one scaffold split protocol.

2
Task Regime MapBest graph model minus best fingerprint baseline

Two regimes appear. GIN leads DILI and ClinTox. RF and XGBoost lead AMES and hERG.

Model choice follows the task regime. Size, balance and chemistry matter more than architecture novelty.
3
Full Benchmark8 methods, 5 datasets, one scaffold split protocol

The heatmap keeps the benchmark honest. It shows graph wins, fingerprint wins and negative LD50 R2 in one view.

  • GIN is strongest on DILI and ClinTox. RF is strongest on AMES, hERG and LD50.
  • Frozen ChemBERTa trails compact baselines on every classification task.
The protocol matters. Scaffold splits make LD50 a warning rather than a win.
4A
LD50 Exposes Split Leakage

Random splits give GIN R2 about 0.49. Scaffold splits send every GNN below zero.

LD50 is a split sensitivity warning. Scaffold splitting is the realistic test.
4B
What 3D Geometry Adds

SchNet trails GINE on ClinTox and AMES. Geometry does not improve ranking accuracy here.

Use 3D as a reliability layer. Prediction spread across conformers flags molecules with unstable scores.
4C
Tox21 Transfer Is Selective

A shared GIN backbone drops macro AUROC by 0.024. Gains are limited to a few related receptor assays.

Shared representation helps only when assays share biology. Otherwise the model sees negative transfer.
5
Conclusions
1
Task regime drives model choice. Graph learning helps on scarce or imbalanced endpoints.
2
Scaffold splits prevent false wins. LD50 changes from promising to unreliable.
3
3D adds reliability evidence. SchNet accuracy trails GINE, but conformer spread flags unstable predictions.
4
Transfer is selective. Multitask learning helps only when endpoints share useful signal.

Setup & Reproducibility

RDKit featurisation, PyTorch Geometric, scikit learn and XGBoost. All runs use a shared Murcko scaffold splitter for cross method comparability. Per run weights and metrics are checkpointed for reproducibility.
